# weather-station_2COMP_2026
 internal: weather station. 2COMP 2026

# Breif + Specs

"Develop a project to showcase your skills and solve a problem. This project will use a range of inputs including at least one sensor and one button. 
But I would strongly encourage you to include a Serial.read() or bluetooth connection for reading/writing values so that your project can receive more human input than just the button press.
This project should use a range of outputs, your ESP32 has a screen, and LEDs built into it that you should take advantage of. 
Any other input or output electronics should be run by the teacher so we can source them. 

Example to help guide your idea;

Weather station
Reading several weather sensors and displaying the readings automatically every minute on a screen with an instant read if a button is pressed. Adding on a LED color to blink, and screen background colour to toggle if one of the values enters a preset range for ‘bad weather’"
